# Documentation

Serenity's documentation. The rest of it is in the code: each file's header
states its contract and its design.

- [`architecture/`](architecture/README.md): the design. Not yet written; it
  comes before any rendering code.
- [`research/`](research/README.md): measurements and investigations, each
  dated, with the machine and toolchain it ran on.
- [`process/`](process/README.md): the workflow, the work queue and the
  project's memory. For contributors, not for readers of the design.
